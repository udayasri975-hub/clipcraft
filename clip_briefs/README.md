# Clip Briefs

This directory stores individual clip briefs generated by the Content Strategist.

## File Naming Convention

```
YYYY-MM-DD_EpisodeTitle_ClipNN.md
```

Example: `2025-05-26_BuildingInPublic_Clip01.md`

## What Each Brief Contains

- Source episode info
- Clip category and rating
- Precise timestamps (start/end)
- Verbatim transcript
- Editorial notes (hook, framing, tone)
- Script outline broken down by seconds
- Platform-specific adaptation notes (YT Shorts, IG Reels, LinkedIn, X Threads)
- Branding instructions for the Video Editor

## Workflow

1. Content Strategist creates briefs and places them here
2. Video Editor picks up briefs from this directory
3. Completed clips are placed in `/home/team/shared/finished_clips/`
